
# Python Calculator

My first Python project!

## Description
A simple calculator built using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Accepts uppercase and lowercase operations
- Handles division by zero
- Displays an error for invalid operations

## Language
Python

## How to Run
1. Install Python.
2. Download calculator.py.
3. Run the file using Python IDLE.
4. Enter two numbers and choose an operation.
